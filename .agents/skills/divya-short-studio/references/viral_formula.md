# Viral formula + channel strategy (Divya Rahasya, from the user's real data, 19 Nov 2026)

Read this before choosing ANY topic or writing ANY script. SKILL.md tells you how to build a Short; this file tells
you which Short to build and why.

## 1. Where the channel stands (be honest with the user)

  1,000-1,400 = YouTube's test audience did not watch to the end, so it stopped pushing.
- Best ever: "Mahabharat Jeetne Ke Baad Arjun Ka Rath..." 2,127 views (33 s). Weakest: no-twist titles
  ("Panchmukhi Hanuman Rahasya" 362, "Ganga Ke Ahankaar..." 367).
- Goal: monetize before 14 Jan 2027 (the user's vow: a pilgrimage for Mummy-Papa).
- **The user chose the Shorts-only path** (long videos only AFTER monetization). So YPP = 10M Shorts views in
  90 days (verify on YouTube's help page whether it becomes 20M from 1 Feb 2027). That only happens if some Shorts
  break out. Never promise virality; maximise the chances.

## 2. Topic formula: known character + unknown twist
Say the topic in one line. If a listener's reaction is "kya?! sach mein?", take it. If it is "achha", drop it.
- ✅ "Jeet ke baad Arjun ka rath jal kar raakh ho gaya" (best performer)
- ✅ "Saat maharathi ek 16 saal ke bachche se dar gaye"
- ✅ "Marte marte bhi Ghatotkach ne poori akshauhini kuchal di"
- ❌ "<deity> ka rahasya", "<festival> kyon manate hain" without a twist, "Kya aapko pata hai..."
Sources: a real granth/version listed in SOURCES; folk versions say "kehte hain". Prefer little-known but TRUE.

## 3. Festival timing
Search spikes before festivals. Have the festival Short ready and uploaded 1-2 days before the date, with the
little-known story behind it (memory: Chhath 1.2K). Upcoming 2026: Dev Uthani (20 Nov), Tulsi Vivah (21 Nov),
Dev Deepawali (24 Nov), Kaal Bhairav (1 Dec), Vivah Panchami (14 Dec), Gita Jayanti (19 Dec), Dattatreya (23 Dec).
Verify every date on Drik Panchang.

## 4. The first 2 seconds decide everything
- Line 1 = the most shocking result. No greeting, no "suniye", no backstory.
- Frame 0 must shock with the sound OFF (it is what people see while scrolling). The hook scene gets the best
  composition of the whole Short and shows the hook line's emotion.
- Title, thumbnail text and line 1 say the same thing.

## 5. 25-second arc (HARD LOCK - see SKILL.md)
0-3 s shock | 3-12 s conflict + ONE line of why | 12-19 s climax shown physically | 19-24 s twist + loop.
Last words must grammatically run into the first line ("...tabhi to" -> "saat maharathi... dar gaye the!").

## 6. Retention mechanics
- Something changes on screen every ~2 s (pose, camera, projectile, crowd, light). 3 s of a standing character = swipe.
- Every verb and drawable noun in the VO happens on screen on that word (voice_sync.md).
- Voice: hold 250-400 ms before reveals, no pauses in action lines, villain lines shouted ("!").

## 7. Cadence and series
- 2 Shorts every day, no gaps. Data so far: 15-18 IST is the best slot (median 1,209) and 07:30 the weakest
  (median 578, n=3). FINAL schedule (user, 19 Nov): Divya Rahasya 12:00 PM + 05:30 PM; RealityShift 01:15 PM +
  04:30 PM. Min 3 h between two Shorts of the same channel. Re-check the slots in the Sunday review.
- If any Short passes ~5,000 views, immediately make 3-4 more in the same angle with new characters (a series:
  "Mahabharat ke yoddhaon ke anjaane anth"). The algorithm looks for more of what just worked.

## 8. 48-hour report card (ask the user for it every time)
YouTube Studio app -> the Short -> Analytics:
- **Viewed vs swiped away**: > 70% viewed = the hook works.
- **Average % viewed**: > 90-100% = the story holds; > 100% = the loop works.
Use the numbers to say exactly what to change next time (which second dropped, which scene).

## 9. Weekly Sunday review with the user
Shorts posted this week, best performer and why, any 5K+ breakout (start a series), one thing to change next week.
Keep the rest of the week focused on making Shorts, not on worrying about the deadline.

## 10. Tone with the user
Honest, warm, never fake hope. The date is a target; the vow (the yatra) stands even if the date slips. Never
suggest shortcuts that endanger the channel: no cloned voices of real people (e.g. a famous saint), no clips from
other channels or shows, no misleading titles.
